📷 Windows OCR Language Packs (30+ Languages)

Louise uses 100% native, offline Windows.Media.Ocr. Run PowerShell as Administrator and run any command below to install official Microsoft neural models:

⚡ 1-Click Multi-Language Pack (Popular European + CJK + Ukrainian)
Installs Ukrainian, English, Polish, German, French, Spanish, Italian & Japanese simultaneously:
@("uk-UA","en-US","pl-PL","de-DE","fr-FR","es-ES","it-IT","ja-JP") | % { Add-WindowsCapability -Online -Name "Language.OCR~~~$_~0.0.1.0" }
🔍 Check Currently Installed OCR Languages
Get-WindowsCapability -Online | Where-Object { $_.Name -like "Language.OCR*" -and $_.State -eq "Installed" }
💡 GUI Alternative: Windows Settings (Win+I) → Time & language → Language & region → Click language ... → Language options → Download OCR.
