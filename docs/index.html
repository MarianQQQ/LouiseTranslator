📷 Windows OCR Language Packs

Louise uses 100% native, offline Windows.Media.Ocr. Run PowerShell as Administrator and paste any command below to install official Microsoft language models:

🇺🇦 Ukrainian (Українська) Add-WindowsCapability -Online -Name "Language.OCR~~~uk-UA~0.0.1.0"
🇵🇱 Polish (Polski) Add-WindowsCapability -Online -Name "Language.OCR~~~pl-PL~0.0.1.0"
🇩🇪 German (Deutsch) Add-WindowsCapability -Online -Name "Language.OCR~~~de-DE~0.0.1.0"
🇫🇷 French (Français) Add-WindowsCapability -Online -Name "Language.OCR~~~fr-FR~0.0.1.0"
🇪🇸 Spanish (Español) Add-WindowsCapability -Online -Name "Language.OCR~~~es-ES~0.0.1.0"
🇮🇹 Italian (Italiano) Add-WindowsCapability -Online -Name "Language.OCR~~~it-IT~0.0.1.0"
🇯🇵 Japanese (日本語) Add-WindowsCapability -Online -Name "Language.OCR~~~ja-JP~0.0.1.0"
🇨🇳 Chinese Simplified (简体中文) Add-WindowsCapability -Online -Name "Language.OCR~~~zh-CN~0.0.1.0"
🇰🇷 Korean (한국어) Add-WindowsCapability -Online -Name "Language.OCR~~~ko-KR~0.0.1.0"
🔍 Check Installed OCR Packs Get-WindowsCapability -Online | Where-Object { $_.Name -like "Language.OCR*" -and $_.State -eq "Installed" }
